# WMH_confluence

# WMH Confluence metric

This repository contains the script that calculates the WMH confluence metric described in Schmidt et al. (2026)

The script expects binary or probabilistic WMH masks as input, e.g. generated by FSL TRUENET or BIANCA. WMH are expected to be organised in a BIDS-like directory
structure:

    input_dir/
        sub-001/
            ses-01/
                *_WMH.nii.gz
        sub-002/
            ...

Results are written to a CSV file containing one row per subject-session.

## Installation

pip install -r requirements.txt

## Command line usage

python3 confluence_metric.py --input_dir --output_dir [--s] [--wmh_string] [--voxel_size]
